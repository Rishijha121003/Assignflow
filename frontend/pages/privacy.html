1. Purpose and Scope

AssignFlow is an academic workflow and assignment management platform designed to facilitate coursework distribution, file submissions, instructor grading, and academic analytics between instructors (teachers) and enrolled students.

This Privacy Policy describes the specific personal and academic data processed by the application, how that data is stored, and the strict access boundaries enforced by software business logic.

2. Information We Collect

AssignFlow collects and processes only the data strictly necessary for academic assignment administration:

  • Account Credentials: Full name, institutional email address, and an encrypted password hash (salted using bcrypt; plaintext passwords are never stored or logged).
  • Role Designation: User account classification as either a Teacher (course creator and evaluator) or a Student (course participant).
  • Course & Enrollment Records: Class names, course join codes, academic semester association, subject codes, and class enrollment rosters.
  • Assignment Materials: Assignment titles, descriptions, due dates, late submission penalty policies, grace periods, and syllabus/assignment PDF attachments uploaded by teachers.
  • Student Submissions & Files: Uploaded coursework files (in supported formats including PDF, DOCX, DOC, TXT, and ZIP up to 10MB), submission timestamps, and attempt counts.
  • Evaluation Records: Instructor feedback notes, awarded scores, grade revision histories, student re-evaluation requests, and deadline extensions.

3. Privacy Wall and Access Controls

AssignFlow enforces strict data isolation and privacy boundaries in application code and database queries:

Student Submission Isolation

Students can view and download only their own uploaded submissions. Cross-student file inspection or download is strictly forbidden and rejected by server authorization guards.

Draft Grade Privacy Wall

Instructor grading remarks and provisional scores remain completely invisible to students until the instructor explicitly publishes them through the "Release Grades" action.

Anonymous Peer Rankings

Class leaderboard and comparative analytics anonymize student identities, displaying peer rankings without exposing personal student names or individual scores to classmates.

Course Ownership Guard

Instructors can only access assignments, submissions, and rosters for classes they created or have been explicitly granted ownership of.

4. Data Storage, Security, and File Retention

  • Database Storage: All structured relational records (users, classes, assignments, submissions, and audit logs) are stored in PostgreSQL within an isolated database schema (assignflow).
  • File Upload Security: Uploaded assignment documents and student submissions are validated by file size (maximum 10MB) and magic-byte inspection (%PDF- verification for PDF documents). Uploaded files are stored on isolated server storage using cryptographically random UUID identifiers to eliminate directory traversal risks.
  • Session Authentication: Authentication is handled using JSON Web Tokens (JWT) stored in HTTP-only, SameSite-restricted cookies and Bearer headers. In production environments, cookies are strictly marked with the Secure flag over HTTPS.
  • Temporary Export Cleanup: Bulk export archives (such as ZIP files of student submissions) are generated in temporary storage and automatically unlinked from the server filesystem immediately following file transmission.
  • Data Retention: Course records, submissions, and grade audit histories are retained for the duration of the active academic period or as mandated by the institution's data retention policy.

5. Data Sharing and Third Parties

AssignFlow does not sell, rent, monetize, or share student or instructor personal data with third-party advertisers, data brokers, or external analytics networks.

Data processing is confined strictly to the operating institution's designated hosting environment. If optional automated email notifications are activated by the operator, outbound notification emails (e.g. deadline reminders or grade release alerts) are routed via the institution's configured SMTP provider.
